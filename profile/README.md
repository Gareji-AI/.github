# Gareji AI

A garage for building apps, tools, and games with AI.

We start small, try things out, and share what we make.

### Projects

- [Gareji Board](https://github.com/Gareji-AI/gareji-board) — A workboard for human–AI teams.
- [Gareji Core](https://github.com/Gareji-AI/gareji-core) — A local foundation for running AI agents with permissions and progress records.
- [Gareji MCP](https://github.com/Gareji-AI/gareji-mcp) — Connects Codex to Gareji projects, context, and progress.
